## Fixing Common App Issues

- Map empty or no nearby results? Confirm location permissions, refresh GPS, and widen your search radius.  
- Listings look outdated? Pull to refresh, check your connection, and report incorrect hours from the shop page.  
- Guides not loading? Free storage space, update the app, and retry on Wi‑Fi if cellular signal is weak.  
- Saved places missing? Sign in with the same account you used originally and enable cloud sync in settings.  
- Notifications too frequent? Adjust alert categories or disable promotional tips while keeping hour-change alerts on.
