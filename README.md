## Common Setup and Display Issues

- Tiles not updating? Confirm the integration is authorized and refresh limits match your plan.  
- Blurry TV output? Use the recommended resolution and test fullscreen mode on the display device.  
- Missing metrics? Map fields correctly in the source connection and republish the dashboard.  
- Access errors? Verify workspace roles so viewers can open shared links without editor permissions.  
- Slow loads on a wall display? Reduce tile count per screen or lower refresh frequency for heavy sources.
